# OIBSIP_level2_task3_ToDoList

Description

A simple To-Do application that helps users manage daily tasks efficiently. Users can add, edit, delete, and mark tasks as completed.

Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Pending Tasks Section
- Completed Tasks Section
- Date and Time Tracking

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download the project files.
2. Open index.html in any web browser.
3. Start managing your tasks.
